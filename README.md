# Testo Helper для Zed

Расширение для редактора [Zed](https://zed.dev), которое добавляет поддержку
языка **Testo** — языка описания тест-кейсов (файлы `*.testo`).
Порт [расширения для VSCode](https://github.com/Romk-a/Testo-Helper).

> Пока расширения нет в официальном реестре Zed, оно устанавливается как
> **dev extension** (Zed собирает его из исходников). Пошаговая инструкция —
> в [INSTALL.md](./INSTALL.md).

## Возможности

- **Подсветка синтаксиса** — ключевые слова, команды, макросы, строки,
  комментарии, подстановки `${PARAM}` и `$<VAR>`.
- **Сниппеты** — 27 готовых шаблонов: циклы, условия, клавиатура, мышь,
  ожидания, включение offline-CPU.
- **Документация при наведении** — синтаксис, параметры и примеры для
  встроенных функций (`wait`, `check`, `press`, `mouse`, `exec`, …), а также
  комментарии-документация макросов.
- **Превью изображений** — наведите курсор на `img "${...}"`, чтобы увидеть
  картинку.
- **Переход к определению** (`Ctrl+Click` или `F12`) — для `include`, вызовов
  макросов и изображений.
- **Счётчик шагов** — рядом с `step` отображается номер шага.
- **Форматирование документа** — отступы, лишние `;`, пустые строки.
- **Открытие тест-кейса в Jira** — для файлов вида `PROJECT-T1234.testo`.

## Установка

Кратко (подробно — в [INSTALL.md](./INSTALL.md)):

1. Установите [Rust через rustup](https://rustup.rs) — Zed собирает
   dev-расширение из исходников.
2. Скачайте репозиторий:
   ```sh
   git clone https://github.com/PoWaR85691/testo-helper-zed
   ```
3. В Zed откройте палитру команд (`Ctrl+Shift+P`) → **`zed: install dev
   extension`** → выберите папку `testo-helper-zed`.
4. Откройте любой файл `.testo`.

## Настройки

Настройки задаются в `settings.json` Zed, в разделе `lsp`:

```json
{
  "lsp": {
    "testo-helper-lsp": {
      "settings": {
        "jiraBaseUrl": "https://jira.company.ru/secure/Tests.jspa#/testCase/",
        "enableImageHover": true,
        "enableDocsHover": true,
        "enableMacroHover": true
      }
    }
  }
}
```

| Настройка | Что делает | По умолчанию |
|-----------|------------|--------------|
| `jiraBaseUrl` | Базовый URL Jira для открытия тест-кейса. Должен заканчиваться на `/` | — |
| `enableImageHover` | Показывать превью изображений при наведении | `true` |
| `enableDocsHover` | Показывать документацию встроенных функций | `true` |
| `enableMacroHover` | Показывать документацию макросов | `true` |

## Использование

- **Сниппеты.** Наберите префикс и нажмите `Tab`, например: `forr` — цикл,
  `ifc` — условие с `check`, `mc` — клик мышью, `w` — `wait`. Полный список —
  в файле [`snippets/testo.json`](./snippets/testo.json).
- **Список клавиш для `press`.** Наведите курсор на слово `press` — появится
  полный список допустимых клавиш.
- **Счётчик шагов `step`.** Это «inlay hints», их нужно включить:
  ```json
  { "inlay_hints": { "enabled": true } }
  ```
- **Форматирование.** Вызовите действие `editor: format` из палитры команд.
  Чтобы форматировать при сохранении:
  ```json
  { "languages": { "Testo": { "format_on_save": "on", "formatter": "language_server" } } }
  ```
- **Открыть тест-кейс в Jira.** Задайте `jiraBaseUrl` (см. выше), откройте файл
  вида `PROJECT-T1234.testo` и вызовите `editor: toggle code actions`.

## Чем отличается от плагина для VS Code

Устройство расширений Zed отличается от VS Code, поэтому часть возможностей
реализована иначе:

| Плагин для VS Code | В Zed |
|--------------------|-------|
| Панель «Testo Helper: Справка» | панелей нет — справка доступна при наведении, а список клавиш показывается при наведении на `press` |
| Команда «Вкл/выкл hover» | настройки `enableDocsHover` и `enableMacroHover` |
| Пункт меню «Format Testo Document» | действие `editor: format` |
| Пункт меню «Open in Jira» в проводнике | code action `editor: toggle code actions` |
| Счётчик шагов как надпись в тексте | inlay hints |
| Всё остальное (подсветка, сниппеты, наведение, определения, превью, форматирование) | работает так же |

## Диагностика

- Если не работает подсветка — проверьте, что в статус-баре (правый нижний
  угол) язык файла определён как **Testo**.
- Логи: палитра команд → **`zed: open log`**.
- Подробный вывод: запустите Zed из терминала командой `zed --foreground`.
